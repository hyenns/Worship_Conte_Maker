# Worship Conte Maker

악보 이미지를 여러 장 넣으면 한 페이지에 같은 너비로 자동 배치해 찬양 콘티를 만드는 GitHub Pages 웹앱입니다.

## 주요 기능

- PNG, JPG, WEBP 이미지 여러 장 업로드
- 곡 순서 드래그 변경
- 흰 여백 자동 제거
- 곡별 수동 여백 자르기
- 곡별 확대·축소 및 세로 정렬
- 가로로 긴 악보를 위한 `세로로 늘려 채우기`
- 모든 악보에 `세로로 늘려 채우기`를 한 번에 적용
- 2곡, 3곡, 4곡 자동 배치
- PNG 다운로드
- 브라우저에서 바로 인쇄

모든 이미지는 브라우저 내부에서만 처리되며 서버에 업로드되지 않습니다.


## v3 추가 기능
- 자르기 창에서 흰색 테두리의 모서리와 변을 직접 드래그해 영역 조정
- 선택 영역 안쪽을 드래그해 영역 전체 이동
- 직접 조정한 값과 아래 슬라이더가 실시간으로 연동


## v4 업데이트
- 좁은 브라우저 창에서 악보 카드의 배치 방식 선택창이 미리보기 영역과 겹치지 않도록 반응형 레이아웃을 보완했습니다.
- 카드 폭에 따라 조절 항목이 3열 → 2열 → 1열로 자동 전환됩니다.
- 화면이 좁아지면 설정/미리보기가 더 일찍 1단 배치로 전환됩니다.
- CSS와 JavaScript에 버전 값을 추가해 GitHub Pages 캐시 문제를 줄였습니다.


## v5 업데이트
- `모든 악보 세로로 채우기` 버튼을 추가했습니다.
- 버튼을 한 번 누르면 현재 추가된 모든 악보의 배치 방식이 `세로로 늘려 채우기`로 변경됩니다.
- 개별 악보는 기존 드롭다운에서 다시 `비율 유지`로 바꿀 수 있습니다.
