# Worship Conte Maker

악보 이미지를 여러 장 추가하면 같은 크기로 정리해 찬양 콘티 PNG를 만드는 브라우저 기반 웹 도구입니다.

## 주요 기능

- PNG, JPG, WEBP 이미지 여러 장 업로드
- 드래그 앤 드롭 업로드
- 카드 드래그로 곡 순서 변경
- 한 페이지당 2곡, 3곡, 4곡 선택
- 흰 여백 자동 제거
- 곡별 확대·축소 및 세로 정렬
- 1920×1080, 2560×1440, A4 가로형 출력
- 페이지별 또는 전체 PNG 저장
- 브라우저 인쇄 기능을 이용한 PDF 저장
- 이미지가 서버에 업로드되지 않고 브라우저 내부에서만 처리

## GitHub Pages 배포

1. `index.html`, `style.css`, `app.js`를 저장소 최상위 폴더에 업로드합니다.
2. 저장소의 **Settings → Pages**로 이동합니다.
3. **Build and deployment**에서 아래와 같이 선택합니다.
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
4. **Save**를 누르고 배포가 완료될 때까지 기다립니다.
