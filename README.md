# Worship Setlist Maker

악보 이미지를 여러 장 넣으면 한 페이지에 같은 너비로 자동 배치해 찬양 콘티를 만드는 GitHub Pages 웹앱입니다.

## 주요 기능

- PNG, JPG, WEBP 이미지 여러 장 업로드
- 곡 순서 드래그 변경
- 흰 여백 자동 제거
- 곡별 수동 여백 자르기
- 곡별 확대·축소 및 세로 정렬
- 가로로 긴 악보를 위한 `세로로 늘려 채우기`
- 모든 악보에 `세로로 늘려 채우기`를 한 번에 적용
- 2곡, 3곡, 4곡 자동 배치
- PNG 다운로드
- 브라우저에서 바로 인쇄

모든 이미지는 브라우저 내부에서만 처리되며 서버에 업로드되지 않습니다.


## v3 추가 기능
- 자르기 창에서 흰색 테두리의 모서리와 변을 직접 드래그해 영역 조정
- 선택 영역 안쪽을 드래그해 영역 전체 이동
- 직접 조정한 값과 아래 슬라이더가 실시간으로 연동


## v4 업데이트
- 좁은 브라우저 창에서 악보 카드의 배치 방식 선택창이 미리보기 영역과 겹치지 않도록 반응형 레이아웃을 보완했습니다.
- 카드 폭에 따라 조절 항목이 3열 → 2열 → 1열로 자동 전환됩니다.
- 화면이 좁아지면 설정/미리보기가 더 일찍 1단 배치로 전환됩니다.
- CSS와 JavaScript에 버전 값을 추가해 GitHub Pages 캐시 문제를 줄였습니다.


## v5 업데이트
- `모든 악보 세로로 채우기` 버튼을 추가했습니다.
- 버튼을 한 번 누르면 현재 추가된 모든 악보의 배치 방식이 `세로로 늘려 채우기`로 변경됩니다.
- 개별 악보는 기존 드롭다운에서 다시 `비율 유지`로 바꿀 수 있습니다.


## v6 업데이트
- 파일 이름 입력란의 기본값을 제거해 처음에는 빈칸으로 표시됩니다.
- 원하는 파일 이름을 직접 입력할 수 있으며, 예시는 placeholder로만 안내됩니다.
- 파일 이름을 비워 둔 채 저장하면 날짜만 파일명으로 사용됩니다.

## v7 제작자 서명과 이스터에그

- 페이지 하단에 `Made with ♡ by Hyein` 제작자 서명이 표시됩니다.
- 제작자 문구를 빠르게 5번 누르거나 키보드로 `hyein`을 입력하면 숨겨진 사진 창이 열립니다.
- 청년부 사진을 저장소 최상단에 `youth-group.jpg`라는 이름으로 업로드하면 숨겨진 창에 자동 표시됩니다.
- GitHub Pages가 Public 저장소인 경우 사진 파일도 공개 URL로 접근할 수 있으므로, 구성원 동의를 받은 사진만 사용하세요.


## v8 사진 표시 수정

- `youth-group.jpg`가 정상 로드되면 안내용 플레이스홀더가 완전히 숨겨지도록 수정했습니다.
- CSS의 `display: grid`가 HTML `hidden` 속성을 덮어쓰던 문제를 해결했습니다.

## v9 확대·축소 버튼 추가

- 각 악보의 확대·축소 슬라이더 양옆에 `−`와 `＋` 버튼을 추가했습니다.
- 버튼을 한 번 누를 때마다 1%씩 미세 조정됩니다.
- 70%~160% 범위에서 조절되며 최솟값과 최댓값에서는 해당 버튼이 자동으로 비활성화됩니다.



## v10 용지 크기 추가

- 페이지 크기 목록을 `A3 → A4 → B4 → 16:9 1920×1080 → 16:9 2560×1440` 순서로 정리했습니다.
- 가장 자주 사용하는 A3 가로형을 기본값으로 변경했습니다.
- A3는 4200×2970px, A4는 2970×2100px, B4는 3640×2570px로 생성됩니다.
- 바로 인쇄 시 선택한 A3·A4·B4 규격에 맞춰 인쇄 페이지 크기가 자동 적용됩니다.


## v11 업데이트
- 넓은 2단 화면에서는 안내 문구가 `카드를 끌어서 순서를 변경하고,` 다음 줄에 `곡별로 여백을 자를 수 있습니다.`로 표시됩니다.
- 화면이 좁아져 1단 배치가 되면 기존처럼 자연스럽게 이어서 표시됩니다.

- 이미지가 없어도 한 페이지 곡 수와 페이지 크기 선택이 빈 미리보기에 즉시 반영
