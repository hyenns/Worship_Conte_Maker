# Worship Conte Maker

악보 이미지를 여러 장 넣으면 한 페이지에 같은 너비로 자동 배치해 찬양 콘티를 만드는 GitHub Pages 웹앱입니다.

## 주요 기능

- PNG, JPG, WEBP 이미지 여러 장 업로드
- 곡 순서 드래그 변경
- 흰 여백 자동 제거
- 곡별 수동 여백 자르기
- 곡별 확대·축소 및 세로 정렬
- 가로로 긴 악보를 위한 `세로로 늘려 채우기`
- 2곡, 3곡, 4곡 자동 배치
- PNG 다운로드
- 브라우저에서 바로 인쇄

모든 이미지는 브라우저 내부에서만 처리되며 서버에 업로드되지 않습니다.


## v3 추가 기능
- 자르기 창에서 흰색 테두리의 모서리와 변을 직접 드래그해 영역 조정
- 선택 영역 안쪽을 드래그해 영역 전체 이동
- 직접 조정한 값과 아래 슬라이더가 실시간으로 연동
